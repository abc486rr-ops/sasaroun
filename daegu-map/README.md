# 사사로운 대구 지도

정적 HTML/CSS와 ES 모듈로 구성합니다. 저장소의 `main` 브랜치가 GitHub Pages의 `/sasaroun/daegu-map/` 경로로 배포됩니다. 빌드 단계는 없습니다.

## 개발 및 검증

저장소 루트에서 서버를 실행합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

다른 터미널에서 테스트를 실행합니다.

```sh
cd daegu-map
npm ci
npm test
npx playwright install chromium
npm run test:e2e
```

브라우저 테스트 기본 주소는 `http://127.0.0.1:8765/daegu-map/`입니다. 별도 서버는 `TEST_URL` 환경 변수로 지정할 수 있습니다. GitHub Actions는 단위 테스트와 Chromium 회귀 테스트를 실행하고 화면 캡처를 보관합니다.

## 주소와 데이터

- 추천인: `#/박사장`
- 장소: `#/박사장/사사로운`
- 전체 목록: `#/전체`
- 전체 지도: `#/전체/지도`
- 내보내는 주소에는 이름을 씁니다. 링크만 보고 누구의 추천인지 알 수 있어야 공유에 의미가 생깁니다.
- 읽을 때는 ID 주소(`#/parksajang/sasaroun`, `#/all/map`)도 받습니다. 한동안 ID 주소가
  나갔던 적이 있어 그것들도 계속 열려야 합니다. 이름이 바뀌면 그 이름으로 나간 링크는
  끊기므로, 이름을 고칠 때는 이미 공유된 링크를 함께 고려하세요.
- `all`, `전체`는 추천인 ID로, `map`, `지도`는 장소 ID로 사용하지 않습니다.
- 아직 오지 않은 달의 손님은 목록에 넣지 않고 콘솔에 경고만 남깁니다.
- `traits`는 문자열 배열, 추천 목록의 각 장소 ID는 추천인당 한 번만 작성합니다.
- 좌표 없는 장소도 카드에 표시되며 외부 지도 검색을 이용할 수 있습니다.

## 오류 복구와 상호작용

저장소 접근이 차단되면 방문 체크는 메모리에서 유지됩니다. 데이터 요청에는 제한 시간이 있으며 재시도 실패 시 오류 화면을 표시합니다. 앱 모듈 로드 실패도 별도로 안내합니다.

지도 타일을 모두 불러오지 못하면 재시도 버튼을 표시합니다. 선택 장소가 없거나 좌표가 없어도 안내가 유지됩니다. 카드 스와이프와 클릭은 분리하고, 포인터 종료는 카드 밖에서도 처리합니다. 주소 복원 시에는 같은 지도 단계 사이의 이동에서도 이전 카드와 전환 효과를 정리합니다.

지도는 OpenStreetMap 표준 타일을 사용하며 출처는 카드에 가리지 않도록 상단에 표시합니다.
원래 쓰던 CARTO Positron 이 API 키를 요구하게 되어 옮겼습니다. 표준 타일은 색이 강해
`.leaflet-tile-pane` 에서 채도를 걷어내 종이 톤으로 맞춥니다 — 그래야 손그림 핀이 묻히지
않습니다. CARTO 키를 발급받으면 Positron 으로 되돌리고 이 보정은 약하게 줄이면 됩니다. 브라우저 기본 캐시와 Referer를 유지하고, 오프라인 다운로드나 타일 미리 받기는 제공하지 않습니다. 자동 회귀 테스트에서는 타일 응답을 대체해 외부 서버에 반복 요청하지 않습니다. 서비스 변경 시 [타일 사용 정책](https://operations.osmfoundation.org/policies/tiles/)을 확인하세요.
