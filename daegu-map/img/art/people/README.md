## 다시 만들 때

원본이 5열 4행 격자이고 배경이 알파 0 이다. 잘라내기는 밝기가 아니라
**알파 채널**로 판단해야 한다 — 배경 RGB 가 0(검정)이라 밝기로 보면
전부 잉크로 잡힌다.

인물 안쪽은 흰색으로 채워져 있으므로 색을 잉크색으로 덮으면 안 된다.
덮으면 선화가 아니라 검은 덩어리가 된다.
